# 图片压缩工具(image-compressor)设计文档

日期:2026-08-02
状态:已由用户确认

## 1. 目标

做一个免费、纯前端、手机可用的在线图片压缩工具:压缩体积、改尺寸、转格式、批量处理。所有处理在浏览器本地完成,图片不上传服务器。

## 2. 非目标(本次不做)

- 不收费、无广告、无会员
- 不做视频压缩/转码(已单独讨论,用户决定先只做图片)
- 不做云存储、账号体系、历史记录
- 不做服务端处理(无服务器、无后端)

## 3. 功能需求

### 3.1 压缩
- 质量滑块(如 0~100 或 0~1),控制 JPEG/WebP 重编码质量
- 保持原尺寸不变,只降低文件体积

### 3.2 改尺寸
- 可选:按目标宽度缩放(输入宽度,等比缩放)
- 可选:按比例缩放(如 50%)
- 默认不缩放(仅压缩)

### 3.3 转格式
- 输出格式可选:保持原格式 / jpg / webp / png
- webp 在老版 Safari 不支持时降级提示(仍可输出 jpg/png)

### 3.4 批量
- 一次选择多张图片
- 结果列表逐张显示:原体积、新体积、压缩率
- 批量时显示处理进度
- 一键打包 zip 下载(仅批量模式;单张直接下载)

### 3.5 设备适配
- 响应式布局,手机浏览器可完整使用(点击选择图片、触屏控件)
- 大上传按钮,避免拖拽在手机上不可用的陷阱

## 4. 页面布局

1. 顶部:标题 + 一句隐私卖点("图片在本地压缩,不上传,保护隐私")
2. 上传区:点击/拖拽上传,支持多选
3. 参数面板:质量滑块、缩放设置、输出格式
4. 结果区:
   - 单张:前后体积对比 + 画质对比(可选并排预览)+ 下载按钮
   - 批量:逐张列表 + 进度 + "打包下载全部"

## 5. 技术设计

### 5.1 架构
纯静态单页应用,无构建、无运行时依赖(仅 CDN 引入 jszip)。

文件结构:
```
image-compressor/
├── index.html      # 页面结构
├── style.css       # 样式(响应式)
├── compress.js     # 图片处理核心:解码 → Canvas 重编码 → Blob
└── app.js          # UI 交互:上传、参数、结果列表、批量、zip 打包
```

### 5.2 处理流程
```
File → createImageBitmap/Image 解码 → 按参数缩放 → canvas.toBlob(mimeType, quality)
→ 生成下载 URL → 显示前后对比 → 下载 / 加入 zip
```

- 压缩:canvas.toBlob('image/jpeg' | 'image/webp', quality)
- 缩放:canvas.width/height 按目标值,drawImage 等比绘制
- 转格式:改变 toBlob 的 mimeType
- 注意:png 无质量参数,转 png 时直接 toBlob('image/png')

### 5.3 依赖
- jszip(CDN,仅批量打包用)
- 其余全部浏览器原生能力

## 6. 错误处理

- 非图片文件:拒绝并提示
- 超大图:Canvas 内存压力时捕获异常,提示缩小后再试或先改尺寸
- webp 不支持(老 Safari):输出 webp 时提示改用 jpg/png
- 无图片时点击下载:禁用按钮或提示先选图
- zip 打包失败:提示单张下载

## 7. 测试

- 浏览器实测(Chrome 桌面):拖拽单张、批量、转格式、改尺寸、压缩率显示
- 手机视图(DevTools 模拟):上传、参数、下载操作可用
- 边界:非图片文件、超大图、空操作
